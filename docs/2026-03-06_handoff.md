## 2) 확인된 핵심 원인 / Confirmed Root Cause
- `/api/health` 응답:
  - `{"status":"ok","mode":"lightweight","fullApiReady":false,"fullApiBootstrapError":"Cannot find module '/var/task/server/auth' imported from /var/task/api/index.js", ...}`
- 즉, Vercel runtime에서 `api/index.js`가 `server/auth`를 로드하지 못해 full API 초기화 실패 -> lightweight fallback 고정.

  - `/api/health`에 `fullApiReady`, `fullApiBootstrapError` 진단 필드 추가
  - lightweight 모드에서 관리자 GET 일부 fallback 응답 추가
