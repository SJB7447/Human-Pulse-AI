## 10) 2026-03-12 Admin reader-article approval fix
- Symptom: pending reader articles loaded in admin, but approve/reject could fail with `Reader article not found.` and leave the queue/history UI out of sync.
- Root cause: `server/storage.ts` could collapse Supabase write or RLS failures into a false not-found response, while in-memory fallback state was not dependable across stateless requests.
- Server fix: approval now rechecks the target row before and after update, and surfaces an explicit backend/RLS write error when the article still exists.
- Client fix: `client/src/pages/admin.tsx` now reloads reader-article data after approve/reject and also refreshes the list after failure so items do not appear to vanish.
- Verification: `npm run lint` passed on 2026-03-12.
